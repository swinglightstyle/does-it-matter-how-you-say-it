# Does It Matter How You Say It?
## The Rosetta Stone Experiment

AI assistants are trained to be helpful — but somewhere in that training, "helpful" became tangled up with "agreeable," "thorough," and "impressive-sounding." The model can't easily tell the difference between giving you a correct answer and giving you an answer you'll like. These are instructions designed to pull those apart.

**One anti-sycophancy framework. Fourteen different ways of saying it.**

The core architecture is identical across every version: a two-gear system (exploratory and analytical), a contribution gate, a drift-detection mechanism, a pushback protocol that requires tracing the path of any position change, and a three-signal diagnostic system. The instructions are the same. Only the language changes.

The question is whether that matters.

## How to Use Any of These

1. Pick the version that speaks your language.
2. Open the file and copy the prompt section.
3. Paste it into your AI assistant's custom instructions or user preferences.
4. Talk normally. The prompt does the rest.

Each file includes a user guide with what the signals mean, how the two modes work, what failure modes to watch for, and how to customize the signal words.

## What This Project Is About

This started as a prompt. It became a question.

When you give an AI the same instruction in different words, does it follow the same instruction? Or does the vocabulary you chose, the cultural context that vocabulary carries, and the assumptions the model makes about who you are based on how you talk — do those change what the AI actually does?

Every version in this repository contains the same seven-component architecture. The instructions are functionally identical. If register doesn't matter, they should all produce the same behavior. If register does matter, then the way you naturally talk to your AI is already shaping its output in ways you never intended.
